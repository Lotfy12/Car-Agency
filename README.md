# 🚀 Car Agency Website

## 🔍 Overview
Car Agency is a modern and responsive car rental / car showroom website built with React.
The project focuses on providing a smooth user experience with clean UI, fast navigation, and organized sections to help users explore cars easily, view details, and interact with the website in a simple way.
---

## 🛠️ Technologies Used


- **React.js** as the React framework
- **Tailwind CSS** for styling
- **forwardRef** for moving from section to another
- **React Router** for navigate between pages
- **React slick** it helps to create a professional slider/carousel easily
---

## ✨ Features

- 📄 See all Cars in a nice way
- ➕ Add Cars
- 📄 See all Reviwing 
- 🗑️ Delete Cars
- ⚡ create a slider using React slick
- 🎨 Styled with Tailwind CSS
- ® Redux for store the data 
---

### To Install and Run the Project
1. Clone the repository:
    ```bash
   git clone https://github.com/Lotfy12/Car-Agency.git
    ```
2. Navigate to the project directory:
    ```bash
    cd project-directory
    ```
3. Install the dependencies:
    ```bash
    npm install
    # or
    yarn install
    ```
4. Run the development server:
    ```bash
    npm run dev
    # or
    yarn dev
    ```
